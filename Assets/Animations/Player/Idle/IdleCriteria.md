# 플레이어 기본형 Idle 작업본

- **출처와 상태** — 사용자 제공 New Player.zip의 New Player/Frames/idle_000.png–idle_095.png를 원본 이름과 바이트 그대로 보관한다. Idle은 기존 작업본으로 보관한다. 사용자 결정에 따라 이번 Idle·Run·Jump·Crouch 비교 세트는 추후 수정할 초안으로 관리한다.
- **규격** — 1024 × 1024 RGBA PNG 96장. ZIP의 New Idle.anim 기준 24 FPS, 4초 반복. 기존 임포트 메타데이터는 PPU 256, 좌하단 피벗 (512, 64)이다. [공통 기준](../../../../../../Characters/Ally/Player/Default/AnimationReference.md) v0.2를 참조한다.
- **검수** — 프레임 순서, 크기, 알파, ZIP 원본과의 바이트 일치를 확인했다. Unity 클립·메타데이터·프리팹·컨트롤러는 원본 ZIP에 보관돼 있다.
- **비교** — [Idle·Run·Jump·Crouch 비교 GIF](../player_default_idle_run_jump_crouch_comparison.gif)는 네 동작을 동일 배율과 접지선에서 4초간 반복한다. Run과 Jump는 16 FPS 기준이다. Crouch의 유지 포즈는 확인용으로 약 0.63초 표시한다. Unity 상태 전환은 미검증이다.

## 버전 상태

- 최신 작업 버전 — 미확인
- 사용자 승인 버전 — 없음

96장의 ZIP 원본은 제작 버전 번호가 확인되지 않아 이 폴더에 보존한다.
