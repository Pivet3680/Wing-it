# ADR-0001: 2D 플랫포머와 변신 펫 중심으로 전환

- 날짜: 2026-11-06
- 상태: 확정
- 관련 문서: [GDD](../GDD.md), [로드맵](../ROADMAP.md)

## 배경

기존 기획은 자동 전진형 공중 런앤건, 반복 상승·활공, 상시 탑승과 2.5D·3D 표현을 중심으로 했다. 사용자가 일반 스테이지의 지형 돌파와 보스전 슈팅을 분리하고 펫의 변신을 핵심 특징으로 삼는 새 방향을 제시했다.

## 검토한 대안

1. 기존 자동 전진·상시 탑승 구조 유지: 과거 시험 내용과 맞지만 새로 정한 펫·블록·마운트의 구간별 역할을 담지 못한다.
2. 일반 구간을 2D 플랫포머와 펫·블록 기믹으로, 보스전을 라이딩 슈팅으로 전환: 사용자가 제시한 현재 방향이다.

## 선택한 방안과 이유

두 번째 방향을 채택한다. 펫은 동행, 블록은 지형 공략, 마운트는 보스전 전투라는 각 형태의 역할을 명확히 나눌 수 있기 때문이다. 일반 스테이지는 좌우 자유 이동과 일반 점프, 화면은 풀 2D를 목표로 한다. 구체적인 블록 배치, 지상 공격, 보스전 이동, 성장·스테이지 구조는 이 결정에 포함하지 않는다.

## 영향 범위

- GDD, 로드맵, 테스트 기준, README의 현행 게임 소개와 개발 우선순위.
- 이동·카메라·충돌·전투 씬과 스크립트의 후속 재검토. 이 ADR만으로 코드 변경이나 전환 완료를 뜻하지 않는다.
- 과거 자동 전진·활공 시험 결과는 이력으로 구분한다.

## 검증 상태

- 기획 문서 반영: 정적 검토 대상.
- 새 게임플레이의 씬 연결, 컴파일, Play Mode 동작: 미검증.
