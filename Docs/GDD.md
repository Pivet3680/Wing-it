> **기획 기준일:** 2026-11-06
> **상태:** 핵심 방향 확정, 세부 규칙 검토 중
> **주의:** 기획은 구현 완료를 뜻하지 않는다. 구현 현황은 [ROADMAP.md](ROADMAP.md)에서 구분한다.

## 1. 한 문장 소개

변신하는 장난감 펫과 함께 지형을 돌파하는 2D 액션 플랫포머. 보스전에서는 펫이 마운트로 변신해 라이더와 함께 횡스크롤 슈팅 전투를 펼친다.

## 2. 확정된 핵심 방향

| 항목 | 현재 방향 |
| --- | --- |
| 장르 | 싱글 플레이 2D 액션 플랫포머와 보스전 횡스크롤 슈팅 |
| 화면·그래픽 | 풀 2D. 장난감 스타일 유지 |
| 일반 스테이지 | 좌우 자유 이동, 일반 플랫포머 점프, 변신 기믹을 통한 지형 돌파 |
| 보스전 | 펫이 탑승 가능한 마운트로 변신하고 플레이어가 올라타 슈팅 전투 |
| 핵심 관계 | 플레이어와 변신하는 펫의 협력 |

일반 스테이지 전체의 자동 전진, 플래피식 반복 상승, 상시 탑승, 2.5D·3D 모델 및 큐브 머티리얼을 목표로 한 구성은 현재 기획에서 제외한다. 과거 시험 씬과 자산이 남아 있어도 이 규칙이 다시 확정된 것은 아니다.

## 3. 펫의 세 형태와 플레이 흐름

| 형태 | 사용 구간 | 역할 | 세부 규칙 상태 |
| --- | --- | --- | --- |
| 펫 모드 | 일반 스테이지 | 작은 새 형태로 플레이어를 따라다니는 기본 동행 상태 | 추적 거리·상호작용 미정 |
| 블록 모드 | 일반 스테이지 | 골판지 블록으로 변신해 밟고 올라가거나 지형·장애물을 통과하도록 도움 | 소환 위치·조작·크기·지속 시간 미정 |
| 라이딩 모드 | 보스전 | 탑승 가능한 크기로 변신해 플레이어와 슈팅 전투 | 이동·공격 조작·전환 연출 미정 |

일반 스테이지의 중심 경험은 자유 이동, 점프, 펫과 블록의 협력이다. 보스전에서는 펫이 커지고 플레이어가 탑승하는 흐름을 목표로 한다. 구체적인 변신 이펙트는 아직 연출 아이디어다. 지상형 보스도 가능하지만 마운트 탑승이 전투에 필요한 이유를 설계해야 한다.

### 블록 모드의 핵심 용도

- 블록을 발판으로 밟아 높은 곳에 오른다.
- 블록을 이용해 지형과 장애물을 통과한다.

어디에 어떻게 블록을 생성할지는 미정이다. 블록을 밀어 스위치를 누르기, 방패로 쓰기, 튀어 올라 점프 보조하기, 바퀴나 태엽으로 추가 변신하기는 **추가 아이디어**이며 현재 필수 기능이 아니다.

## 4. 조작과 전투

- **일반 스테이지:** 좌우 자유 이동과 일반 플랫포머 점프가 확정된 방향이다. 실제 키 배치, 점프 높이·횟수·공중 제어는 정하지 않았다.
- **지상 전투:** 공격을 사용할 방향이지만 직접 총을 쏠지, 블록·펫 능력과 어떻게 결합할지는 미정이다. 조준 범위와 발사 방식도 미정이다.
- **보스전:** 탑승 슈팅은 핵심 방향이다. 상하좌우 자유 비행과 자동 전진 기반 슈팅 중 어느 방식인지, 공격 입력과 카메라 연출은 미정이다.

## 5. 성장과 스테이지

- 기존 진행도 기반 3단계 증강은 **그대로 유지하기로 확정하지 않았다.** 삭제하거나 새 성장 구조로 재설계할지 검토한다.
- 한 판 내 성장, 영구 성장, 아이템, 체력·실패·재시도 규칙은 미정이다.
- 일반 스테이지에서 지형 돌파와 액션을 중심으로 한다. 스테이지 클리어형과 반복 플레이 중심 로그라이트 구조 중 진행 방식은 미정이다.
- 마운트 종류 및 형태별 차이, 일반 적과 보스의 패턴, 스테이지 수와 길이는 미정이다.

## 6. 다음 기획 결정

1. **블록 변신의 기본 규칙:** 플레이어 근처 즉시 소환 또는 원하는 위치 설치, 크기·거리·재사용 조건을 정한다. 이 결정이 점프 높이와 지형 간격 설계에 영향을 준다.
2. **지상 전투:** 플레이어 총기와 펫·블록 능력의 역할을 정한다.
3. **보스전 이동:** 자유 비행 또는 자동 전진 기반 슈팅을 선택한다.
4. **증강·성장:** 기존 3단계 증강의 폐기 또는 재설계를 결정한다.
5. **스테이지 구성:** 클리어형 또는 반복 플레이형 구조를 결정한다.

이 항목들은 순서 제안이며 확정된 조작법이나 구현 명세가 아니다.

## 7. 첫 플레이 가능 프로토타입의 목표

- 좌우 이동과 일반 점프로 짧은 2D 지형을 통과한다.
- 펫이 동행하고 블록으로 변신해 적어도 한 지형 문제를 해결한다.
- 보스전 진입 시 라이딩 형태로 전환해 슈팅 전투의 기본 흐름을 시험한다.

블록 조작과 보스전 이동 규칙이 아직 미정이므로 이 목록은 **목표 범위**다. 구현 및 검증 완료 여부는 [ROADMAP.md](ROADMAP.md)와 [TESTING.md](TESTING.md)를 따른다.
