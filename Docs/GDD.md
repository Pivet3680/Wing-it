# Wing it! — 게임 기획서 (GDD)

> **문서 상태:** 초기 기획 초안
> **기준:** 사용자와 논의한 기획 내용. README는 프로젝트 소개와 실행 안내를 제공하며, 상세 기획은 이 문서를 기준으로 관리한다.
> **주의:** 이 문서는 기획 방향과 목표 범위를 설명한다. 실제 구현 여부는 프로젝트 파일과 검증 결과로 확인하며, 진행 현황은 `ROADMAP.md`에서 관리한다.

## 1. 게임 개요

| 항목 | 내용 |
| --- | --- |
| 프로젝트명 | Wing it! |
| 장르 | 싱글 플레이 2.5D 횡스크롤 런앤건 액션 로그라이트 |
| 배경 | 장난감들이 살아 움직이는 세계 |
| 주인공 | 날지 못하는 새 장난감과 등에 탄 사람 장난감 |
| 핵심 경험 | 자동 전진 중 고도와 속도를 조절하고 조준·사격해 장애물과 적을 돌파 |
| 개발 방향 | 핵심 조작의 재미를 확인하는 소규모 프로토타입 우선 |
| 플랫폼 | PC 우선 고려. 모바일 대응 여부와 방식은 미정 |

**한 문장 소개:** 날지 못하는 새 장난감과 등에 탄 사람 장난감이 함께 달리고 날아가며, 고도 조절과 사격으로 장난감 세계의 위협을 돌파하는 횡스크롤 액션 게임.

## 2. 기획 상태와 핵심 원칙

이 문서의 구체적인 아이디어는 상태를 구분해 읽는다.

- **핵심 방향:** 현재 기획의 중심으로 삼는 플레이 경험과 조작 방향이다. 수치와 세부 규칙은 여전히 조정될 수 있다.
- **검토 중:** 유력한 제안이나 구현·테스트 후 결정할 사항이다.
- **미정:** 아직 선택하지 않은 사항이다. 구현에 임시값이 필요하면 테스트용임을 밝힌다.

1. **이동과 공격을 함께 즐긴다.** 전진 흐름을 유지하면서 고도와 위험을 판단하고 적을 조준·사격한다.
2. **비행을 주요 플레이 방식으로 삼는다.** 지상 달리기도 가능하며, 지형과 장애물에 따라 공중 이동과 전환한다.
3. **적은 입력으로 의미 있는 선택을 만든다.** 비행 방식, 공격 대상, 회피와 아이템 사용을 판단하게 한다.
4. **핵심 조작을 먼저 확인한다.** 증강, 보스와 다른 확장 요소에 앞서 이동·비행·사격·회피의 재미를 검증한다.
5. **기획과 구현을 구분한다.** 이 문서에 적힌 기능은 구현 완료를 뜻하지 않는다.

## 3. 세계관과 캐릭터

- 배경은 거대한 사물과 다양한 장난감이 등장하는 장난감 세계다. 구체적인 분위기와 설정은 미정이다.
- **새 장난감:** 스스로 날 수 없으며, 지상에서는 달리고 공중에서는 등에 부착된 날개로 비행·활공한다.
- **사람 장난감:** 새의 등에 타고 날개 조작을 돕고 총기로 적을 공격한다.
- 두 장난감은 플레이어 관점에서 하나의 캐릭터처럼 조작한다. 캐릭터별 별도 입력이나 전환 시스템은 현재 범위에 없다.
- 외형, 성격, 스토리, 적의 정체와 스테이지 테마는 미정이다.

## 4. 플레이 흐름과 화면 표현

### 목표 플레이 흐름

1. 플레이어는 스테이지에서 자동으로 오른쪽으로 진행한다.
2. 고도와 속도를 조절해 지형·장애물을 통과하거나 피한다.
3. 마우스로 조준·사격해 적을 상대한다.
4. 진행 중 증강을 얻어 능력이나 플레이 방식을 바꾼다. 획득 시점과 선택 방식은 미정이다.
5. 스테이지 구간을 돌파해 보스에 도전하는 구조를 목표로 한다. 구간 수, 보스 등장 방식과 승패 조건은 미정이다.

### 화면 표현

- 2.5D 횡스크롤 시점을 사용한다. 화면에서 플레이어의 가로 위치를 비교적 일정하게 유지하고 배경·지형·장애물·적이 다가오는 연출을 **검토 중**이다.
- 플레이어를 월드 좌표상 이동시키는 방식과 주변 오브젝트를 이동시키는 방식 중 무엇을 사용할지는 구현 단계에서 결정한다. 화면 표현만으로 내부 이동 방식을 단정하지 않는다.
- 3D 공간과 깊이감 있는 배경을 지향하며, 시차 연출과 카메라 구성은 미정이다.

## 5. 기본 조작 방향

| 입력 | 의도한 동작 | 상태 |
| --- | --- | --- |
| `Space` 짧게 눌렀다 놓기 | 손을 뗄 때 순간 상승. 반복 입력으로 고도를 조절하고 공중 이동을 이어감 | 핵심 방향 |
| `Space` 길게 누르기 | 설정한 시간이 지나면 일반 점프보다 낮게 상승한 뒤 하강을 늦추고 전진 속도를 높이는 고속 활공. 활공 후 손을 뗄 때는 상승하지 않음 | 핵심 방향, 높이·시간 수치 조정 가능 |
| 마우스 이동 | 횡스크롤 XY 평면에서 전방 180도 이내로 총기 조준 | 핵심 방향 |
| 마우스 왼쪽 버튼 | 조준 방향으로 사격. 누르고 있는 동안 간격을 두고 연속 발사 | 핵심 방향, 간격 수치 조정 가능 |
| 마우스 오른쪽 버튼 | 아이템 사용 | 검토 중 |

짧은 입력과 활공을 구분하는 시간, 일반 점프와 활공 시작 점프의 높이, 중력, 하강 속도, 가속량, 연사 방식과 전방 범위 안의 세부 조준 방식은 미정이다. 고속 활공의 속도는 기본 속도의 약 1.5배를 **초기 시험값 후보**로 삼을 수 있지만, 확정 수치가 아니며 테스트로 조정한다.

## 6. 핵심 시스템

### 6.1 자동 전진과 지상 이동

- 기본적으로 오른쪽으로 전진하는 흐름을 가진다.
- 지상에서는 달리는 연출을 사용하고, 지형에 따라 지상과 공중 이동을 전환한다.
- 공중 이동을 주요 재미로 삼되, 지상 구간의 비중과 공중 체류 시간은 플레이 테스트로 조정한다.
- 전진 속도, 충돌 처리와 속도 변화 방식은 미정이다.

### 6.2 상승·중력·활공

- 짧은 Space 입력은 손을 뗄 때 플래피 버드처럼 반복 가능한 순간 상승을 일으킨다.
- 입력하지 않을 때는 중력에 따라 하강한다.
- 긴 Space 입력은 설정한 시간이 지나면 일반 점프보다 낮게 상승하고, 하강을 완화하며 전진 속도를 높이는 고속 활공으로 전환한다. 활공 후 손을 떼면 상승하지 않는다.
- 상승과 활공을 구분하는 시간 수치, 지면 접촉과 천장 충돌 처리는 추가 검증 대상이다.
- **초기 검증 질문:** 반복 상승과 활공이 서로 구분되는 선택으로 느껴지고, 함께 사용할 때 직관적인가?

### 6.3 조준과 사격

- 사람 장난감이 횡스크롤 XY 평면에서 마우스 방향으로 총기를 조준해 공격한다. 조준 가능 범위는 오른쪽 전방 180도이며, 마우스가 뒤쪽 위·아래를 가리키면 각각 수직 경계로 제한한다. 정확히 뒤쪽 수평을 가리키면 정면을 향한다.
- 이동·비행 중에도 사격할 수 있는 것을 목표로 한다.
- 초기 프로토타입은 기본 무기 하나와 단순한 적 피격 반응으로 조작감을 확인한다.
- 초기 시험용 탄환은 기본 3D 도형으로 표현하고, 버튼을 누르는 동안 일정 간격으로 발사한다. 정식 발사체, 연사 간격의 최종 수치, 탄약·재장전, 피해 규칙과 무기 종류는 미정이다.

### 6.4 지형·장애물·적

- 플레이어는 장애물을 피하거나 적절한 고도로 통과한다. 지상과 공중에 서로 다른 위험을 배치하는 방식을 검토한다.
- 첫 시험 씬에는 지상과 공중에 피해야 할 기본 도형 장애물을 둔다. 접촉 시 플레이어 색이 잠시 바뀌는 피격 표시만 적용하며, 체력·사망·재시도 규칙은 아직 정하지 않는다.
- 위쪽이 막힌 공간에서는 고도 조절과 회피가 더 중요해질 수 있다.
- 초기 프로토타입은 기본 행동을 가진 적 한 종류로 시작하는 방안을 권장한다.
- 보스가 아닌 일반 적은 재사용 가능한 프리팹으로 관리한다.
- 시험용 일반 적은 화면 안에서 가까운 플레이어에게 접근하고 일정 간격으로 탄환을 발사하며, 플레이어 탄환에 맞으면 제거된다. 화면에 한 번 나타난 뒤 화면 밖으로 나가면 새 공격과 접근을 멈추고, 다시 나타나지 않으면 5초 뒤 제거된다. 이는 정식 적 패턴이나 피해 규칙을 확정한 것이 아니다.
- 장애물 종류, 충돌 피해·즉사, 적의 패턴·체력·보상, 난이도 상승과 배치 방식은 미정이다.

### 6.5 증강

- 진행 중 획득하는 증강으로 능력이나 플레이 스타일이 달라지는 로그라이트 구조를 지향한다.
- 비행·이동·무기 성능에 영향을 주는 효과는 아이디어 단계다.
- 획득 시점, 선택 방식, 희귀도, 중첩 규칙과 효과는 미정이다.
- 증강 시스템은 첫 번째 조작 검증 프로토타입의 필수 범위가 아니다.

### 6.6 스테이지·보스·아이템

- 스테이지형 진행을 우선 고려하며 엔들리스 모드는 후순위 아이디어다.
- 여러 구간을 지나 보스에 도전하는 흐름을 목표로 하나, 보스전의 구조와 패턴은 미정이다.
- 우클릭 아이템 사용은 검토 중이다. 아이템 종류, 획득, 보유 제한과 소모 규칙은 미정이다.
- 체력, 사망·재시도, 점수, 저장, 체크포인트, UI와 사운드도 후속 기획 대상이다.
- 스킨, 랭킹, 온라인 기능과 수익화는 초기 프로토타입 범위에 포함하지 않는다.

## 7. 첫 번째 플레이 가능 프로토타입

### 확인할 범위

- [ ] 횡스크롤 화면과 자동 전진의 체감
- [ ] 지상 이동과 중력
- [ ] 반복 가능한 순간 상승
- [ ] 긴 입력에 따른 고속 활공과 짧은 입력의 구분
- [ ] 마우스 조준과 기본 사격
- [ ] 간단한 지형·장애물 충돌
- [ ] 단순한 적 한 종류와 피격 반응
- [ ] 이동·비행·사격·회피를 연속해서 경험하는 짧은 테스트 구간

이 목록은 목표 범위이며 완료 현황이 아니다. 실제 진행은 `ROADMAP.md`, 결과와 판정 기준은 `TESTING.md`에서 관리한다.

### 후순위 범위

복잡한 증강 조합과 밸런싱, 정식 보스전, 다수의 스테이지와 무기, 영구 성장, 랭킹·온라인 기능, 모바일 최적화와 수익화는 핵심 조작 검증 이후에 고려한다.

### 초기 검증 질문

1. 자동 전진 속도와 공중 고도 조절이 직관적인가?
2. 반복 상승과 고속 활공이 서로 다른 선택으로 느껴지는가?
3. 이동 중 조준·사격이 부담스럽지 않고 재미있는가?
4. 장애물과 적이 의미 있는 판단을 요구하는가?
5. 짧은 구간을 반복 플레이하고 싶은가?

이 질문만으로 합격 여부를 확정하지 않는다. 구체적인 절차와 기준은 `TESTING.md`에서 정한다.

미정 사항은 임의로 최종 결정하지 않는다. 구현에 임시값이 필요하면 테스트용 설정임을 밝히고 결과를 기록한다.
