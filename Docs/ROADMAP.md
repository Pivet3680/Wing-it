# Wing it! — 개발 로드맵

> **기획 기준:** [GDD.md](GDD.md), 2026-11-06
> **현황 기준:** 2026-11-10 기존 Player의 Idle·Run 전환과 접지 검사, 새 Player의 Idle 프리팹 추가. Play Mode 동작은 검증 대기.
> **상태 원칙:** 기획 확정과 구현·검증 완료를 구분한다.

## 1. 현재 우선순위

첫 목표는 **좌우 자유 이동·일반 점프·펫 동행·블록 발판**을 연결한 짧은 2D 지형 구간이다. 이어서 보스전 라이딩 슈팅의 기본 흐름을 시험한다. 일정이나 출시일은 아직 정하지 않는다.

| 순서 | 단계 | 상태 | 완료 기준 |
| --- | --- | --- | --- |
| 0 | 2D 프로젝트 기반 확인 | 완료 | 템플릿 씬·렌더러·패키지, Editor 임포트·컴파일과 기본 씬 Play Mode 확인 |
| 1 | 블록 변신 규칙 결정 | 예정 | 배치·회수·크기·사용 제한과 지형 설계 기준 결정 |
| 2 | 2D 플랫포머 조작 시험 | 검증 대기 | 좌우 이동과 일반 점프를 짧은 구간에서 직접 검증 |
| 3 | 펫·블록 지형 돌파 시험 | 예정 | 펫 동행과 블록 전환으로 한 지형 문제를 해결하고 회귀 확인 |
| 4 | 보스전 라이딩 슈팅 시험 | 예정 | 이동·공격 규칙을 정한 뒤 변신·탑승·기본 전투를 검증 |
| 5 | 전투·성장·스테이지 확장 | 보류 | 미정인 규칙을 결정하고 범위·검증 기준 마련 |

`검증 대기`는 관련 코드·에셋·씬 구성은 있으나 이번 변경의 Editor 및 Play Mode 검증이 남았다는 뜻이다. `예정` 및 `보류` 항목은 구현 완료로 표시하지 않는다.

## 3. 과거 프로토타입과 현재 상태

2026-11-03의 이전 자동 전진·활공·사격·적 시험 구현과 2026-11-06의 스프라이트 시험 씬은 활성 프로젝트에서 제거했다. `Assets`, `Packages`, `ProjectSettings` 원본과 미커밋 자산은 GitHub에서 제외한 로컬 `Art/LegacyUnityProject-2026-11-06.zip`에 보관했다. 과거 Play Mode 결과는 현재 기획의 완료 근거가 아니다.

활성 `Assets`에는 2D 템플릿에 더해 `PlayerMovement2D.cs`, 기존 Player의 Idle·Run 애니메이션, 새 Player의 Idle 프리팹, 펫 이미지와 Ground 후보 스프라이트가 있다. 씬에는 기존 Player와 일부 Ground 에셋이 배치되어 있다. 펫 동행·블록 변신·보스전은 아직 구현되지 않았다. 이전 프로젝트의 필요한 자산은 로컬 보관본에서 선별해 가져올 수 있다.
