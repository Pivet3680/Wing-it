# Wing it!

**Wing it!**은 변신하는 장난감 펫과 지형을 돌파하는 **싱글 플레이 2D 액션 플랫포머**입니다. 보스전에서는 펫이 탑승형 마운트로 변신해 횡스크롤 슈팅 전투를 펼치는 방향입니다.

> **기획 기준:** 2026-11-06. 현재 Unity 프로젝트는 `Universal 2D` 템플릿으로 다시 만든 초기 상태입니다. 아래 게임 설명은 구현 목표이며, 실제 진행 상태는 [개발 로드맵](Docs/ROADMAP.md)을 확인하세요.

## 프로젝트 정보

| 항목 | 내용 |
| --- | --- |
| 게임 엔진 | Unity `6000.3.21f1` (`ProjectSettings/ProjectVersion.txt` 기준) |
| 개발 언어 | C# |
| 게임 형태 | 싱글 플레이, 풀 2D 횡스크롤 |
| 개발 형태 | 1인 개발 |

## 게임의 핵심 방향

- 일반 스테이지: 플레이어가 좌우로 자유롭게 이동하고 일반적인 플랫포머 점프로 진행합니다.
- 펫 모드: 작은 새 형태의 펫이 플레이어를 따라다닙니다.
- 블록 모드: 펫이 골판지 블록으로 변신해 발판이 되거나 지형·장애물 돌파를 돕습니다.
- 보스전: 펫이 탑승 가능한 마운트로 변신하고 플레이어가 올라타 슈팅 전투를 합니다.

블록 소환 조작, 지상 공격, 보스전 이동·공격 방식, 증강·성장과 스테이지 진행 구조는 아직 미정입니다. 기존 자동 전진·플래피식 점프·상시 탑승·2.5D/3D 계획은 현재 목표에서 제외했습니다. 자세한 확정·미확정 구분은 [GDD](Docs/GDD.md)에 있습니다.

## 현재 프로젝트와 실행 안내

1. Unity Hub에서 이 프로젝트 폴더를 Unity `6000.3.21f1`로 엽니다.
2. `Assets/Scenes/SampleScene.unity`를 엽니다. 이 씬은 Orthographic 카메라와 `Global Light 2D`만 있는 기본 2D 씬입니다.
3. 현재 플레이어, 펫, 블록, 지형, 보스와 조작 스크립트는 활성 `Assets`에 없습니다. Play Mode는 빈 2D 씬 확인용입니다.

활성 프로젝트에는 공식 `Universal 2D` 템플릿의 `Renderer2D`와 2D 패키지가 적용되었습니다. 교체 전 `Assets`, `Packages`, `ProjectSettings`는 로컬 `Art/LegacyUnityProject-2026-11-06.zip`에 보관했습니다. `Art` 폴더와 압축 파일은 GitHub 저장소에 포함하지 않습니다.

### 종이비행사 스프라이트 시험 이력

사용자가 추가한 별도 시험 씬 `WingItSpriteReplacement.unity`와 `PaperPilotSpriteTest.unity` 및 관련 스프라이트는 로컬 보관본에만 있습니다. 이전 안내의 자동 전진, 짧은 `Space` 점프, 약 0.3초 이상 입력하는 활공과 `jump`·`glide` 프레임은 **이전 기획의 시험 내용**이며 현재 활성 프로젝트에서는 실행할 수 없습니다. 달리기 프레임은 원본 팩에서 실험적 품질로 표시되어 있었습니다.
