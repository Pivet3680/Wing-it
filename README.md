# Wing it!

**골판지 발판을 딛고, 같은 펫에 올라타 보스와 싸우는 2D 액션 플랫포머.**

Wing it!은 장난감과 접은 종이로 꾸민 세계를 변신하는 펫과 함께 탐험하는 싱글 플레이 게임입니다. 평소에는 곁을 따라다니는 펫이 지형 앞에서는 발판이 되고, 보스를 만나면 함께 싸울 수 있는 탈것으로 바뀝니다.

**1인 개발 중 · Unity 6 · C# · Universal Render Pipeline 2D**

![별 모자를 쓴 플레이어가 왼쪽에서는 잉키 블록을 딛고 점프하고, 오른쪽에서는 박쥐 날개를 편 잉키에 올라타 태엽 장난감 보스와 싸우는 모습](Docs/Media/gameplay-concept.png)

*AI로 제작한 플레이 콘셉트 예시. 왼쪽은 블록 발판, 오른쪽은 탑승 슈팅입니다.*

## 어떤 게임을 만들고 있나요?

- **일반 스테이지에서는 펫으로 길을 만듭니다.** 달리기와 점프로 이동하다가 한 번에 닿지 않는 턱을 만나면, 펫을 골판지 블록으로 바꿔 중간 발판으로 삼습니다. 올라간 뒤에는 펫을 다시 불러 함께 이동합니다.
- **보스전에서는 펫에 올라타 횡스크롤 슈팅을 합니다.** 펫이 플레이어를 태울 만큼 커지고, 플레이어는 펫을 타고 보스의 공격을 피하며 맞서 싸웁니다.

## 앞으로 추가할 내용

1. **블록으로 돌파하는 짧은 스테이지.** 높은 턱과 장애물이 있는 구간을 만들고, 펫 블록을 어디에 놓고 어떻게 회수할 때 플레이가 자연스러운지 시험합니다.
2. **첫 탑승 보스전.** 펫의 탑승 형태 전환부터 이동, 공격, 피격까지 짧은 전투로 연결합니다. 보스전의 이동 방식과 공격 조작은 검토 중입니다.
3. **지상 전투와 스테이지 진행.** 지상에서 플레이어와 펫이 각각 어떤 역할로 싸울지 정하고, 스테이지 진행 방식과 성장 구조를 검토합니다.

## 현재 프로토타입

## Unity에서 실행하기

1. Git LFS가 설치된 환경에서 저장소를 클론합니다.

   ```sh
   git lfs install
   git clone https://github.com/Pivet3680/Wing-it.git
   ```

2. Unity Hub에서 클론한 프로젝트 폴더를 **Unity `6000.3.28f1`**로 엽니다.
3. [`Assets/Scenes/GameScene.unity`](Assets/Scenes/GameScene.unity)를 열고 **Play**를 누른 뒤 **Game** 뷰를 클릭합니다.

### 프로토타입 조작

| 입력 | 동작 |
| --- | --- |
| `A` / `D` | 좌우 이동 |
| `W` | 점프 |
| `S` 길게 누르기 | 지상에서 웅크리기 |
| `Space` | 대시 |
| 마우스 휠 버튼 클릭 | 커서 위치에 펫을 블록으로 배치하거나 펫으로 되돌리기 |
