# Wing it!

**Wing it!**은 장난감 세계를 무대로, 날지 못하는 새 장난감과 등에 탄 사람 장난감이 함께 모험하는 **싱글 플레이 2.5D 횡스크롤 런앤건 액션 로그라이트**를 목표로 합니다.

> **개발 상태:** 자동 전진, 점프, 활공, 전방 조준·연사, 시험용 적과 회피 장애물을 포함한 기본 도형 프로토타입이 있습니다. 아래의 나머지 게임 기능은 기획 방향이며, 실제 구현 여부는 Unity 프로젝트의 코드·씬·에셋과 테스트 결과를 확인해야 합니다.

## 게임의 핵심 콘셉트

플레이어는 자동으로 오른쪽으로 전진하는 두 장난감을 하나의 캐릭터처럼 조작합니다. 새 장난감은 지상에서 달리고 공중에서 날개로 비행·활공하며, 등에 탄 사람 장난감은 날개 조작과 총기 사용을 담당합니다.

핵심 플레이는 **고도와 속도를 조절하면서 조준·사격하고 장애물과 적을 돌파하는 것**입니다. 장난감 세계의 스테이지를 진행하고 증강을 얻어 능력을 바꾸며 보스에 도전하는 흐름을 목표로 합니다.

## 핵심 조작 방향 (기획 기준)

| 입력 | 기획된 동작 |
| --- | --- |
| `Space` 짧게 눌렀다 놓기 | 손을 뗄 때 순간 상승 |
| `Space` 길게 누르기 | 설정 시간이 지나면 낮게 점프한 뒤 활공해 하강을 늦추고 전진 속도를 높임. 손을 뗄 때 추가 상승 없음 |
| 마우스 이동 | 횡스크롤 기준 오른쪽 전방 180도 내 총기 조준 |
| 마우스 왼쪽 버튼 | 누르는 동안 설정 간격으로 시험용 탄환 연속 발사 |
| 마우스 오른쪽 버튼 | 아이템 사용 (구상 중) |

활공 전환 시간과 비행 물리의 최종 수치, 무기와 아이템의 구체 동작은 프로토타입 테스트와 추가 기획을 통해 정합니다.

## 진행 및 개발 방향

- **초기 프로토타입:** 자동 전진, 지상 달리기와 중력, 순간 상승, 고속 활공, 조준·사격, 간단한 장애물·적과 테스트 스테이지를 통해 핵심 조작의 재미를 확인합니다.
- **후속 목표:** 핵심 플레이를 확인한 뒤 증강 조합, 스테이지 다양화, 보스전을 단계적으로 구체화합니다.
- 증강 획득 조건과 선택 방식, 보스전 구조, 체력·재도전, 클리어 조건은 아직 확정되지 않았습니다.
- 그래픽은 장난감 세계를 표현하는 3D 환경과 2.5D 사이드 스크롤 연출을 지향합니다. 구체적인 아트 스타일과 카메라 연출은 추후 결정합니다.

## 프로젝트 실행

1. Unity Hub에서 프로젝트 폴더를 엽니다.
2. 프로젝트 버전 `6000.3.21f1`에 맞는 Unity 에디터를 선택합니다.
3. `Assets/Scenes/WingItMovementPrototype.unity`를 열고 Play Mode를 실행합니다. `SampleScene`은 Unity 기본 씬입니다.
4. 플레이어 구체는 자동으로 오른쪽으로 전진하며 화면 가로폭의 약 27.5% 지점에 표시됩니다. `Space`를 짧게 눌렀다 놓으면 손을 뗄 때 일반 점프를 합니다. 길게 누르면 설정 시간이 지난 시점에 낮게 점프한 뒤 활공하여 전진 속도가 높아지고 낙하 속도가 제한됩니다. 활공 후 손을 떼면 추가 점프 없이 기본 이동과 중력에 따른 하강으로 돌아갑니다.
5. 플레이어의 `WingItAutoFlight` 컴포넌트에서 `Normal Jump Height`(일반 점프 높이), `Hold Jump Height`(활공 시작 점프 높이), `Hold To Glide Seconds`(전환 시간), `Glide Fall Speed`(최대 낙하 속도), `Glide Forward Speed Multiplier`(전진 배율)를 조절할 수 있습니다. 카메라의 `WingItSideCamera` 컴포넌트에서 `Target Viewport X`(화면 가로 위치)를 조절할 수 있습니다. 현재 수치는 조작감 검증을 위한 임시값입니다.
6. 마우스를 움직이면 총구가 전방 180도 내에서 조준합니다. 뒤쪽 위·아래를 가리키면 각각 수직 방향으로 제한되고, 정확히 뒤쪽 수평을 가리키면 정면을 향합니다. 왼쪽 버튼을 누르고 있으면 기본 구체 탄환을 연속 발사합니다. 플레이어의 `WingItGun` 컴포넌트에서 `Fire Interval`(발사 간격)을 조절할 수 있습니다.
7. 씬 앞쪽의 일반 적 두 개는 `Assets/Prefabs/WingItRegularEnemy.prefab`의 인스턴스입니다. 화면 안에서 가까워지면 플레이어 쪽으로 다가오며 탄환을 발사하고, 플레이어 탄환 한 발에 제거됩니다. 한 번 화면에 나타난 뒤 밖으로 나가면 새 발사와 접근을 멈추고 5초 뒤 제거됩니다. 프리팹의 `Offscreen Despawn Seconds`로 시간을 조절할 수 있습니다. 플레이어 피해와 정식 적 패턴은 아직 구현하지 않았습니다.
8. 지상과 공중에 보라색 시험용 장애물이 있습니다. 닿으면 플레이어가 잠시 붉어졌다가 원래 색으로 돌아옵니다. 플레이어의 `WingItPlayerHitFeedback` 컴포넌트에서 `Flash Seconds`를 조절할 수 있습니다. 체력 감소나 사망은 아직 없습니다.
